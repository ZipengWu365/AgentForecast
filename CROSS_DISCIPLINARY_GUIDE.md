# Cross-Disciplinary Starter Flows

These case names are demo starter flows for software walkthroughs.

They are useful for:

- showing pack generation on domain-flavored series
- demonstrating artifact outputs
- illustrating routing and report structure
- giving new users realistic entrypoints

They are not used as submission-grade scientific evidence unless a case has explicit provenance, baseline choice, failure analysis, and a non-claim statement.

## Current policy

- keep cross-domain examples public as demos
- keep submission evidence focused on one explicit public software evidence case
- do not imply domain-grounded scientific conclusions from these demos alone
