# Scientific Software Contribution

The contribution in this release is software architecture and reproducibility discipline.

## Main contribution

- a compact forecast-to-publish pack API
- explicit strict research semantics
- stable artifact manifest and metadata provenance
- stable tool and MCP envelopes
- reviewed support tiers exposed in code and docs

## Why this matters

The package reduces mismatch between:

- quick demo code and reproducible outputs
- convenience routing and protocol-strict research use
- human-readable artifacts and agent-readable payloads

## What this contribution is not

- a new estimator family
- a universal forecasting benchmark paper
- a general replacement for specialized forecasting frameworks
