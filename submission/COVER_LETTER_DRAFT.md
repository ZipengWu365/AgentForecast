# Cover Letter Draft

We submit `agentforecast v1.9.0` as a software-first scientific software contribution. The release centers on a reviewed forecast-to-publish layer with explicit support tiers, a strict research API through `OnlineForecaster`, a stable artifact contract, and stable tool/MCP consumption surfaces.

This submission does not claim a new forecasting method or field-wide predictive superiority. Instead, it emphasizes reproducibility, stable public interfaces, artifact provenance, and honest disclosure of reviewed versus experimental functionality. The package now includes reviewed `MLForecast` and `River` adapters within a clearly bounded claim, plus a streaming evaluation appendix that is explicitly separated from the main release claims.

Residual risks remain visible. Public community adoption is still limited, optional adapters remain outside the reviewed boundary unless promoted, and cross-domain examples are documented as demos rather than domain-validation studies.
