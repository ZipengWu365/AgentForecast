Strict mode

Use OnlineForecaster or compare APIs with strict backend resolution.

  • requested backend must be available
  • missing backends raise an error
  • resolution provenance is recorded in metadata and artifact manifests
Docs

Convenience mode

Use high-level pack APIs for demo and operational publishing.

  • backend='auto' may choose among installed candidates
  • explicit fallback only happens when allow_backend_substitution=True
  • routing and fallback details stay visible in provenance metadata
