# Code of Conduct

This project aims to be welcoming and respectful.

## Expected behavior

- be respectful and constructive
- focus criticism on code and ideas, not people
- assume good intent and ask clarifying questions before escalating

## Unacceptable behavior

- harassment, abuse, or intimidation
- hateful or discriminatory language
- doxxing or threats

## Reporting

Open a private issue or contact the maintainers through the release process configured for the repository.
